CURRENT STATE — what is verified working (as of 2026-06-12, full audit)
==================================================================
  - Build gates: npm run build (dark-theme guard + tsc + vite) PASS;
    node --check backend PASS; terraform validate + fmt clean; secret scan
    (scripts/check-secrets.sh) PASS. CI (.github/workflows/ci.yml) runs the
    same gates + gitleaks on every push/PR.
  - Safe production smoke (npm run smoke:prod): 14/14 — health, consultants
    list (11 profiles), Cyrillic slug, public routes, sitemap/robots,
    anonymous 401 on protected routes, prod-origin CORS preflight.
  - Security posture: all /me/*, /bookings, /admin/* return 401 anonymously;
    auth claims come only from the API GW JWT authorizer; booking mutations
    enforce ownership (no IDOR found in review); no XSS sinks
    (no innerHTML/dangerouslySetInnerHTML; JSON-LD via textContent); IAM
    scoped to the 3 tables + CV bucket; CORS allowlist = www + CloudFront
    (localhost is only enabled temporarily during QA and always reverted —
    re-verified after every pass).
  - Social login: Google + LinkedIn + Apple live via Cognito hosted UI.
    Apple uses the Services ID as client_id; /oauth2/authorize handoff
    verified for all three. OAuth errors now surface as a clear banner on
    /auth (e.g. email-collision case) instead of failing silently.
  - Package/access model (2026-06-14): ALL expert tiers are PAID — Start 9.99 /
    Grow 29.99 / Spotlight 99.99 EUR per month; clients are free; every pricing
    button is "Очаквай скоро" (Stripe pending). No consultant approval anymore —
    a profile is public when the account is ACTIVE (admin-comped/invited or paid)
    AND passes the quality bar. The 11 existing profiles were grandfathered
    (comped). New mentor onboarding is INVITE-ONLY: admin emails an invite
    (POST /admin/invites -> SES link /auth?invite=TOKEN), redeemed at bootstrap
    for a free comped consultant account; self-serve consultant signup shows an
    invite-only notice. Admin can RESTRICT/full-suspend any account
    (PUT /admin/users/{id}/restrict): hides the profile + blocks bookings +
    disables Cognito sign-in (reversible). Catalog orders Spotlight > Grow first.
    Admin can still grant a package (audited) + feature/message accounts.
  - Admin monitoring (/admin "Преглед на платформата"): numbers are real, not
    placeholders. Account totals now come straight from the Cognito user pool
    (ListUsers, read-only IAM) — the source of truth for registrations — with a
    confirmed/непотвърдени split and a breakdown by login (Имейл/Google/Apple/
    LinkedIn). "Активирани профили" is the DynamoDB mirror (created on first
    authenticated request); a note surfaces the drift (registered-but-not-yet-
    activated). Other tiles scan DynamoDB live: public profiles, bookings by
    status + upcoming confirmed sessions, messages, reviews + average rating,
    confirmed sessions, and a first-party page-view counter. Degrades gracefully
    to DB counts if Cognito is unreachable.
  - Designer/tester doc (June): fully implemented and DOM-verified — new
    copy site-wide, 7 области (+auto-scroll), directory Препоръчани (≥4.5,
    verified min 4.6) / Водещи buttons, photo badges, −50% card photos,
    3-tier pricing card with current tier marked.
  - Owner round-2 fixes: photo lightbox + all 5 modals render via portal to
    <body> — true fullscreen popups above the sticky header (root cause was
    a CSS specificity rule overriding position:fixed; reproduced, fixed,
    re-measured). Form pairs top-aligned (Име/Имейл measured equal at 52px).
    Age clamped 18–95 (input + save validation + backend). Документи moved
    to a header files icon + /files page (upload + share with consultants
    you have a confirmed session with). Ad box rotates the real creatives
    from assets/advertisement/ (mp4 muted/loop + jpg). In-profile Известия
    panel removed (header bell + /notifications cover it).
  - Responsive: all pages checked at 1280px and 375px — 0 horizontal
    overflow, 0 console errors on fresh loads; dark mode clean; calendar
    tap targets ≥40px.
